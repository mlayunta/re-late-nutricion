# 🥗 Re-Late Nutrición Saludable

**Aplicación PWA de nutrición saludable para rehabilitación cardíaca**

---

## 📋 Descripción

Re-Late es una aplicación web progresiva (PWA) diseñada para pacientes en rehabilitación cardíaca y personas que buscan una alimentación saludable. Funciona **100% offline** y cumple con el **RGPD** (todos los datos se almacenan localmente).

## ✨ Características

| Pestaña | Funcionalidad |
|---------|--------------|
| 🍽️ **Plato** | Buscador de alimentos, cálculo nutricional automático, semáforo cardio |
| 📷 **Recetas** | Catálogo con evidencia científica (PREDIMED, AHA, EFSA) |
| 📅 **Plan** | Generador de menús semanales y lista de la compra |
| 🏆 **Retos** | Gamificación, rachas e insignias |
| 📊 **Diario** | Analítica, radar de hábitos, informes PDF |

## 👤 Perfiles de Usuario

- Cardíaco
- Hipertenso
- Dislipemia
- Diabetes tipo 1
- Diabetes tipo 2

Cada perfil ajusta dinámicamente los umbrales del semáforo nutricional.

## 🚀 Despliegue en GitHub Pages

1. Crea un repositorio en GitHub (ej: `re-late-nutricion`)
2. Sube todos los archivos de este paquete
3. Ve a **Settings → Pages**
4. Selecciona la rama `main` y carpeta `/` (root)
5. Tu app estará disponible en: `https://tuusuario.github.io/re-late-nutricion/`

## 📱 Instalación como App

1. Abre la URL en Chrome/Safari
2. Pulsa el menú (⋮ o compartir)
3. Selecciona **"Añadir a pantalla de inicio"**

## ⚠️ Aviso Legal

> Esta aplicación tiene carácter **educativo e informativo**. No sustituye el consejo de profesionales de la salud. Los valores nutricionales son orientativos y deben contrastarse con tablas oficiales (BEDCA, USDA) para uso clínico estricto.
